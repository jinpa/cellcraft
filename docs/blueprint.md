# **App Name**: CellCraft

## Core Features:

- Editable Grid Display: Render a scrollable, editable spreadsheet-like grid with distinct rows and columns, allowing for dynamic cell sizing.
- Cell Selection & Navigation: Allow users to select individual cells via mouse click and navigate between cells using keyboard arrow keys.
- Direct Cell Text Entry: Enable users to type directly into a selected cell, updating its content in real-time.
- Local Data Persistence: Automatically save the current grid data to the browser's local storage to retain content across sessions.

## Style Guidelines:

- Primary action color: A professional and clean blue (#2766C0) to indicate focus and interactivity.
- Background color: A very light, desaturated blue-gray (#EBF1F6) providing a neutral canvas for data entry.
- Accent color: A vibrant, clear aqua (#49C3DB) for highlights and selected cell outlines to maintain high visibility.
- Primary font: 'Inter' (sans-serif) for all text, chosen for its clear, neutral, and highly readable qualities in data-heavy interfaces.
- Use minimalist, outline-based icons for any future functionalities, ensuring they are easily recognizable and maintain a clean aesthetic.
- A clean, grid-focused layout with defined cell borders, maximizing screen real estate for the spreadsheet and minimizing distracting chrome.
- Subtle, quick animations for cell selection and hover states, providing instant feedback without interrupting the user's flow.
